# 🌤️ Cloudex – MERN Stack Weather Application

Cloudex is a full-stack weather forecasting application built using the MERN stack (MongoDB, Express.js, React.js, Node.js). It delivers real-time weather data, forecasts, and location-based climate insights through a clean and responsive interface.

---

## 🚀 Features

- 🌍 Real-time weather information
- 📍 Location-based weather detection
- 🔍 Search weather by city name
- 🌡️ Temperature, humidity, wind speed & pressure
- ☁️ Weather condition icons & descriptions
- 📱 Fully responsive design (mobile & desktop)
- ⚡ Fast and lightweight UI
- 🔐 Secure API handling with backend

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Axios
- Tailwind CSS / CSS3
- HTML5

### Backend
- Node.js
- Express.js
- REST API

### Database (Optional / Extension)
- MongoDB (for saving search history or user preferences)

### API
- OpenWeatherMap API (or any weather API)
